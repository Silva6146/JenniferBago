# JenniferBago

Post Full Description: "A tool that would allow my clients to select multiple symptoms they are experiencing and then generate a list of associated supplements. I would also like the supplement list generated to be able to count how many symptoms recommended that supplement."

I posted this project since the domain and website were shutdown. There is placeholder images for the person profile picture but was able to download images of it from Upwork. At the time I didn't have knowlegde of React. The Backend was made using PHP and the Frontend pure HTML and CSS with assets given by the Client. I decided to remake this project with the new Knowlegde with hardcoded data to show my Frontend skills.

The features of this website were the ability to Log In and Sign Up for Clients. The tool where the Client could select one or more Symptom(s) and it would show the Supplements related to them. And the PayPal payment method.

This Frontend project uses React and Bootstrapp.
